UAV / Robotics

Dual-2D-LiDAR UAV for Indoor SLAM, 3D Reconstruction, and Precision Landing

A custom 10-inch PX4 UAV using one horizontal 2D LiDAR for indoor SLAM and one vertical 2D LiDAR for sequential scanning and 3D point-cloud reconstruction. The concept was validated in PX4 SITL and RViz, then deployed on a physical platform with Raspberry Pi 5. The system also supports AprilTag-based precision landing in a GPS-denied local frame.

Research / Soft Robotics

Double-Attack Mechanical Thrombectomy

First-author proof-of-concept thrombectomy device combining rotational clot interaction with soft-actuator-driven axial reciprocation. Benchtop testing showed approximately 7% localized suction improvement.
