Selected work

Flagship • UAV / Autonomy / Mapping

Dual-2D-LiDAR UAV for Indoor SLAM, 3D Reconstruction, and Precision Landing

Developed a dual-LiDAR UAV architecture for indoor GPS-denied operation. One horizontal 2D LiDAR supports SLAM, while a vertical 2D LiDAR provides scans for 3D reconstruction.

  • Validated the concept in PX4 SITL and RViz using lawnmower, spiral, and diagonal survey trajectories.
  • Combined sequential LiDAR scans with UAV pose to form a 3D point cloud.
  • Deployed the platform on a custom 10-inch UAV with Raspberry Pi 5 and two RPLIDAR sensors.
  • Implemented indoor AprilTag precision landing using PX4 offboard control and a local coordinate frame.
  • Horizontal-LiDAR SLAM is deployed; vertical-LiDAR reconstruction is under active improvement.
