# Dual-LiDAR UAV media

This project is presented in two portfolio panels.

## 1. Simulation and pipeline validation

Planned media:
- CAD system configuration
- PX4 SITL / RViz mapping views
- simulated 3D point cloud
- trajectory and coordinate-frame validation
- 2D SLAM and 3D mapping demo links

## 2. Real-world deployment

Planned media:
- physical 10-inch UAV cover photo
- onboard hardware and sensor integration
- real indoor SLAM map
- real vertical-LiDAR point cloud
- AprilTag and RViz verification
- field precision-landing setup
